# Dashboard de Gestão de Capacitações | 2026 

## Sobre o projeto

Este projeto consiste no desenvolvimento de um dashboard interativo no Google Looker Studio, com foco no acompanhamento e na análise de indicadores relacionados às capacitações e treinamentos da área de Qualidade.

A proposta é transformar dados em informações visuais e estratégicas, facilitando o monitoramento dos resultados, a identificação de oportunidades de melhoria e o apoio à tomada de decisões.

## Objetivos

- Monitorar indicadores de capacitações e treinamentos.

- Facilitar a análise dos resultados.

- Acompanhar o desempenho das ações de capacitação.

- Contribuir para uma gestão mais estratégica e orientada por dados.

## Ferramentas utilizadas

- Google Looker Studio


## Observação

Projeto desenvolvido para fins de demonstração e composição de portfólio, utilizando dados fictícios, sem informações confidenciais ou dados reais da empresa.
